# 冷库调度台（单页 · 白板拼箱）

从空仓库起步的冷库装柜调度台，解决「急货常被普通货占位」的问题。纯 HTML/CSS/JS，无构建、无依赖，直接用浏览器打开 `index.html` 即可（也可 `python3 -m http.server` 后访问）。

## 预置数据

- 三个温区柜（各 30 m³）：
  - `F1` 冷冻（-25℃ ~ -18℃）
  - `C1` 冷藏（0℃ ~ 4℃）
  - `M1` 恒温（8℃ ~ 15℃）
- 六票货物，含货号、温区、体积、截港时刻、冷处理状态（证明是否齐全）。截港时间以首次打开页面的时刻为基准（如 +0.8h、+1.2h、+5h…），刷新后保持不变；点「恢复预置数据」会重新生成。

## 调度规则

1. **温区匹配**：货物只能入同温区柜。
2. **容积留足**：柜内剩余体积 ≥ 货物体积才入柜。
3. **急货优先挑柜**：截港不足 2 小时的货排前（已过截港的更前），同档按截港时刻升序。
4. **已入柜不挪**：调度只处理排队中的货，不动在柜货。
5. **缺冷处理证明排队**：缺证货挂起，点「补齐证明」后自动参与下一轮调度。
6. **改温区/体积**：释放原柜位并重新排队，下一轮按新条件入柜。

挑柜采用最佳适配（剩余容积最接近货物体积的柜优先），为大票急货留出整柜空间。

## 页面功能

- 顶部按温区筛选（全部 / 冷冻 / 冷藏 / 恒温），标签上显示该温区待处理数。
- 柜卡片：温区、占用条、已用/剩余体积、在柜货标签、本温区待处理数。
- 货物表：截港倒计时与「急/已截港」标记、证明状态、排队/在柜状态，以及补齐证明、手动入柜、改单操作。
- 「手动调度一轮」按当前时刻重跑规则；状态自动保存到 `localStorage`。

## 分层维护

| 文件 | 职责 |
| --- | --- |
| `js/rules.js` | **判断层**：温区、截港、容积、急货排序、调度计划，全为纯函数，不碰 DOM 与存储 |
| `js/storage.js` | **本地保存层**：`localStorage` 读写、入柜/释放/补证/改单的数据变更 |
| `js/app.js` | **交互层**：渲染与事件，判断调 `Rules`，保存调 `Store` |
| `index.html` / `styles.css` | 结构与冷色调样式 |

改规则动 `rules.js`，改存储动 `storage.js`，改界面动 `app.js`，互不牵连。
